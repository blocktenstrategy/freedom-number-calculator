# Freedom Number Calculator

A four-step calculator that shows how much you need invested to retire on your own terms.

**Inputs:** target monthly income, other retirement income (social security, rental, business, others), current age, retirement age.

**Outputs:**
1. Inflation-adjusted target income
2. Target minus other income (with a per-source breakdown table)
3. Your Freedom Number (annual shortfall ÷ withdrawal rate)
4. Monthly investment needed, with a 4%–10% return slider and a growth chart

Inflation (3%) and withdrawal rate (4%) are adjustable under "Adjust assumptions".

## Run it

Open `index.html` in a browser. No build step or dependencies.

*Educational estimate, not financial advice.*
